## Proyecto de fin de curso

Este proyecto con funcionalidades e-commerce incluye:
+ Gestión del Carrito y Autenticación de Usuarios.
+ CRUD de Productos con MockAPI.
+ Optimización de Diseño y Responsividad.
+ Funcionalidades de Búsqueda y Paginación.
+ Diseño responsive.

Tecnologias utilizadas:
+ React 19 - Biblioteca principal para la interfaz
+ React Router DOM - Navegación entre páginas
+ React Bootstrap - Estilizado y diseño responsivo
+ Lucide React - Iconografía consistente
+ React Toastify - Para las notificaciones
+ React Helmet - Para el SEO
+ MockAPI - Backend simulado para productos
+ LocalStorage - Persistencia de datos del cliente

### Uso de la aplicacion

Para usuario no logueado:
+ Iniciar sesión en la aplicación
+ Navegar por el catálogo de productos
+ Buscar productos usando la barra de búsqueda
+ Agregar productos al carrito

Para usuarios logueados:
+ Acceder al carrito para finalizar la compra
+ Crear nuevos productos con imagen y detalles
+ Editar productos existentes
+ Eliminar productos del catálogo

### Instalación local

Clona el repositorio:
```
git clone https://github.com/KevDeto/proyecto-final-reactjs.git
```
Accede al proyecto:
```
cd proyecto-final
```
Descarga las dependencias:
```
npm install
```
Inicia el servidor de desarrollo:
```
npm run dev
```

El proyecto está desplegado en Netlify: [Proyecto-Final](https://mostazaproject.netlify.app/)
